# Promoter dataset

Place the official UCI `promoters.data` file in this directory. The repository
includes that source file, downloaded from the UCI Machine Learning Repository
dataset **Molecular Biology (Promoter Gene Sequences)**, dataset ID 67
(DOI: 10.24432/C5S01D), licensed CC BY 4.0. Its rows label 57-base *E. coli*
sequences with `+` (promoter) or `-` (non-promoter); the instance name is the
middle comma-separated field. The loader expects `promoters.data` here.
